# Security Policy

## Supported Versions

We actively provide security fixes and maintenance updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Cloud Sync, please do NOT disclose it publicly in issues or discussions.

Instead, please send a report to:
- **Email**: `security@cloudsync.example` (or contact the maintainer directly via GitHub Security Advisories)

Please include:
1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the behavior.
3. Affected versions, OS, and configurations.

We will review your submission promptly and coordinate a patch and responsible disclosure.
