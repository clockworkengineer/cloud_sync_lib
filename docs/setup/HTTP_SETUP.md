# HTTP / HTTPS Directory & REST File Server Setup Guide

Cloud Sync includes native support for HTTP and HTTPS file servers (equivalent to Rclone's `http` remote), allowing you to synchronize or mirror files with Apache, Nginx, Caddy, Python `http.server`, or custom REST file servers.

---

## 1. Supported Server Formats

- **HTML Autoindex Pages**: Standard `<a href="...">` directory listings generated by Apache `mod_autoindex`, Nginx `autoindex on`, Caddy `file_server browse`, and Python `http.server`.
- **JSON Autoindex Pages**: JSON array directory listings (`[{"name": "file.txt", "size": 1024, "is_dir": false}]`) produced by Nginx `autoindex_format json` or Caddy.
- **HTTP Methods**:
  - `GET` & `HEAD`: Listing directories, probing `Content-Length` / `ETag`, and downloading files.
  - `PUT`: Uploading files and creating remote directories.
  - `DELETE`: Removing files on writable HTTP servers.

---

## 2. Configuration (`config.toml`)

Add the `[http_credentials]` block to your `config.toml`:

```toml
[http_credentials]
# Base HTTP or HTTPS endpoint URL
url = "https://files.example.com/shared"

# Optional Basic Auth credentials
username = "deploy_user"
password = "my_http_password"

# Or optional Bearer token authentication
# bearer_token = "eyJhbGciOiJIUzI1NiIs..."

# Optional remote subpath
destination_folder = "releases"

# Optional sync mode ("one_way", "two_way", "one_way_no_deletions")
sync_mode = "two_way"

# Optional transparent compression (CLZ1) and encryption (AES-256-GCM)
# compress = true
# encryption_password = "my-zero-knowledge-key"
```
